# Troubleshooting

**Antivirus removed it.**
Add an exclusion for the folder you extracted into, then run it again. The tool is not
code-signed, so a fresh build is sometimes flagged.

**Nothing seems to happen.**
It works quietly and closes by itself. Give it a few seconds, then start the game.

**Still happening.**
Delete the game's settings folder so it rebuilds the files, start the game once, then run
the tool again.

**"Windows protected your PC".**
More info -> Run anyway. The file is not signed.
